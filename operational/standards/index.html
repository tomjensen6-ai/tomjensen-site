Standards & Structure

Which identification standard to use, and in what order. Most of the work is picking the right one, then sticking to it.

1. Use the standard that already exists

Most sites already have a naming standard, even if it is badly written down. The order I follow:

  • The owner's or client's standard.
  • The national or sector standard.
  • An internal structure, only where neither exists.

A new naming scheme on a site that already has one gives you two names for the same breaker. That is worse than one imperfect name.

2. The Norwegian example: TFM

TFM (Tverrfaglig merkesystem) was developed by Statsbygg and is widely used in Norwegian buildings. It is now part of the NS 3457 series: NS 3457-7 covers identification of systems, NS 3457-8 covers component classes, and NS 3457-9 covers marking of systems and components in buildings. System codes come from NS 3451.

A TFM tag has three parts, each with its own sign:

+building =system.number -component

+ where it is: the building
= which system: the system code from NS 3451, plus a number for each system of that type
- which component: a letter code for the type of component, plus a running number

Owners use different versions of TFM, so the exact codes vary. Always use the owner's own TFM rules and code lists.

For physical marking and sign design, Statsbygg's design guide PA 0803 is a useful reference. It names TFM as one of the ID numbering systems it supports.

3. Outside Norway

Standards and rules vary from country to country, and many owners have their own scheme. The most common ones I would look at:

  • IEC 81346: an international standard for reference designations, common in industry and energy.
  • ISO 19650: information management for buildings over their whole life, including BIM.
  • IFC (ISO 16739): the open format for the building model itself, so geometry and data can move between tools.
  • COBie: a common format for handing over asset data from building projects, used mostly in the UK and US. In Norway, public owners such as Statsbygg usually ask for IFC models instead.

Classification tables vary too: Uniclass in the UK, OmniClass in North America, NS 3451 in Norway.

Whichever standard a site uses, the principle is the same: one approved logic for the whole site.

4. What this means for procedures

A procedure names the asset by its approved tag, never "the UPS in electrical room 2". If the asset can't be identified clearly in the field, the procedure isn't ready to use.

If the tag in the procedure doesn't match the label on the equipment, stop. Find out which one is wrong before you touch anything.
