Asset Identification

How I would tag equipment so the name in the procedure, the label on the equipment and the record in the maintenance system all point to the same thing.

1. Why it matters

"Check the UPS" is a bad instruction on a site with eight UPS systems. The tag in the procedure must match the label in the room, the drawings, the asset register, the maintenance system and the alarm in monitoring. When one of them is wrong, people guess. Guessing is how the wrong breaker gets opened.

2. What a tag must answer

  • Where is it? Site, building, room.
  • Which system does it belong to? Power, cooling, fire, security.
  • Which component is it? The exact unit.

A tag is unique, stays the same for the life of the asset, and can be read by someone who has never been on the site.

3. The format used in this library

Where the site has no approved standard (see Standards & Structure), the examples in this library use:

SITE-BUILDING-ROOM-SYSTEM-ASSET-RUNNINGNO
SITE1-B1-ER2-UPS-001-01

SITE1 is the site, B1 the building, ER2 electrical room 2 and UPS the asset type. 001 is the system, and 01 the unit within it. Three UPS units working together as one system in the same room would be UPS-001-01, UPS-001-02 and UPS-001-03.

A part inside a unit that is worth tracking on its own, such as a UPS power module, adds a part code: SITE1-B1-ER2-UPS-001-01-M03 is module 3 in UPS unit 01. The tag stays with the position. When a module is replaced, the new one takes the same tag, and the serial numbers show which module was there when.

A room or area on its own stops after the room code: SITE1-B1-DH1 is data hall 1.

Outdoor equipment uses room code 000: SITE1-B1-000-FUEL-001-01 is a fuel tank outside the building.

Room codes used in the examples: ER electrical room, GR generator room, DH data hall, RC reception, LB loading bay.

Note: Each site sets its own room codes. Within one company, use the same codes on every site, so a technician who moves between sites reads them the same way.

4. Labels on the equipment

A tag only helps if you can find it in the room. A good label is:

  • visible during normal work, without opening anything
  • durable enough for the room: heat, dust, cleaning
  • readable in the room's own light
  • fixed to the asset itself, not to a door or cover that can end up on another cabinet
  • changed when the equipment is changed

5. QR codes

A QR code next to the tag can open the asset record: manual, maintenance history, procedure. It sits next to the visible tag, never instead of it. At 3 a.m. with no signal, you still have to read the label.

The link must point to the controlled record, not a file on someone's laptop or an old copy of the manual.

6. One tag in every system

The same tag should appear in the maintenance system (CMMS), the building model (BIM), the handover documentation (FDV), monitoring and the procedures. Then you can go from an alarm to the equipment, to the procedure and to its history without guessing.

7. When equipment changes

When equipment is replaced, moved or removed, update the label, the asset register, the drawings, monitoring and the procedures together. Miss one, and the documents slowly stop matching the room.

8. Check before you use a tag scheme

  • Every critical asset has a unique tag.
  • Tags match the drawings and the asset register.
  • Labels can be read in the room, on the asset itself.
  • The same tag is used in CMMS, monitoring and procedures.
  • Replaced equipment is updated everywhere.
  • A technician from outside can understand the logic.

Example Tags

  • SITE1-B1-ER2-UPS-001-01: UPS system 1, unit 1
  • SITE1-B1-GR1-GEN-001-01: Standby generator
  • SITE1-B1-000-FUEL-001-01: Fuel tank (outdoor)
  • SITE1-B1-DH1: Data hall 1
